# Council wiki

[Open the public Council wiki](https://afsc-assessments.github.io/Council_related_site/).

This website brings together public assessment resources, catch analyses, formatting tools, and SSC records. It includes full available GOA and BSAI catch histories (AKFIN 2003–2025; NOAA CAR110 2013–2025), harvest-specification histories (BSAI 1986–2026; GOA 1986–2024), downloadable data and reproducible source, and an illustrative Tier 3 figure. Source status and missing-data notes accompany the series. Each linked project retains its own scientific status and version history.

Internal review documents remain in the separate private workspace. This repository contains the selected rendered website and its supporting files.

GitHub Pages serves the root of `main`; `.nojekyll` preserves the static Quarto assets.
