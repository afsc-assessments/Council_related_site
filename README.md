# Council wiki

[Open the public Council wiki](https://afsc-assessments.github.io/Council_related_site/).

This website brings together public assessment resources, catch analyses, formatting tools, and SSC records. It includes selected BSAI catch products and an illustrative Tier 3 figure. Each linked project retains its own scientific status and version history.

Internal review documents remain in the separate private workspace. This repository contains the selected rendered website and its supporting files.

GitHub Pages serves the root of `main`; `.nojekyll` preserves the static Quarto assets.
