ABC reduction

Historical reductions below maximum permissible ABC and risk-table evidence.

The main report compares BSAI and GOA groundfish risk-table scores with SSC reductions below maximum permissible ABC (maxABC) during 2018 to 2024. It explores the relationship through regressions and examples that translate risk scores into probabilities.

Open main report Public source repository

Evidence and interpretation

The risk-table data file contains 302 stock-year rows across 45 distinct stock labels. Completed risk tables account for part of this collection. The report’s regression analysis uses 21 quantified stock-year ABC reductions, entered by hand. It excludes years carried forward from previous advice and reductions without a stated amount.

Scoring conventions changed in 2019, 2023, and 2024. The report’s sensitivity analysis checks results after putting scores on a common scale. Consult this comparison when interpreting changes across years. The fitted relationships describe historical SSC behavior and remain exploratory.

The main report explores a proposal from the 2020 EBS Pacific cod assessment using assumed values for CV (coefficient of variation, a measure of relative uncertainty) and delta (position within the probability range assigned to a risk level). These scenarios are exploratory examples of a proposed decision rule.
